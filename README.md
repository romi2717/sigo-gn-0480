## Descripción

SIGO-GN — Sistema Integral de Gestión Operativa.

Proyecto de la materia Sistemas Operativos,
desarrollado utilizando React y Vite.


## Práctica 2: Panel base y control de acceso

### Funcionalidades
- Inicio de sesión con tres usuarios de prueba.
- Validación de usuario y contraseña.
- Panel de bienvenida con datos del usuario.
- Protección de la ruta /dashboard.
- Cierre de sesión.
- Diseño responsivo en tonos rosas.

### Tecnologías utilizadas
- React
- Vite
- React Router
- CSS
- localStorage

### Pruebas realizadas
1. Inicio de sesión con datos correctos.
2. Intento de inicio de sesión con datos incorrectos.
3. Cierre de sesión.
4. Acceso al Dashboard sin iniciar sesión.

### Ejecución del proyecto
1. Abrir la carpeta del proyecto en VS Code.
2. Ejecutar npm install.
3. Ejecutar npm run dev.
4. Abrir la dirección que aparece en la terminal.
